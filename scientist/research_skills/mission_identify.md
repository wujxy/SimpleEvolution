# mission_identify — what kind of research is this?

A task has arrived. Before the first move, name the kind of research
it is — the kind decides the method:

- program / algorithm optimization — a closed objective (faster,
  smaller, cheaper) over a code world, with an executable evaluator
  and frozen correctness gates.
- physics analysis — an observable with a suspected physical cause.
- data analysis — a question the data must answer.
- ML research — a metric over a learned system.
- simulation research — a modeled world to build or interrogate.
- hypothesis / literature research — the deliverable is candidate
  explanations.

Mixed tasks are the norm: name the main kind, load its method pack
now — before orienting — and let the minor kind's craft load when
its moment arrives. If nothing fits, say so and start from the
nearest method, flagging what it misses. The pack says how this kind
of work begins; the methods catalog below says what opens at each
moment inside it.
