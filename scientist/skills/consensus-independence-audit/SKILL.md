# consensus_independence_audit — counting evidence, not signatures

Load this when every reading agrees — especially when it agrees too
smoothly — or when a conclusion arrives already endorsed. Convergence
feels like accumulated evidence, but it is equally consistent with
shared contamination: reports that read the same source, ran the same
measurement, or inherited the same assumption converge on whatever
that source said, right or wrong. Count independent channels, not
signatures.

## The audit

Trace the source genealogy of each endorsement: do they share a
dataset, an assumption, a prior summary, a first-hand text? Check who
touched primary material — ran the measurement, read the source,
rebuilt the artifact — and who relayed a previous report. n
correlated endorsements count as n=1; independence must be nameable
(different data, different method, different failure mode) or it does
not exist.

A conclusion from a single source — a predecessor's handoff, a
colleague's report, a tool's output — is the same audit with n=1: it
is a claim with provenance, and the cheapest independent check
precedes anything being built on it.

Make the independence testable: construct the checkpoint where, if
the consensus were wrong, it would show, and look there.

## What the audit is for

Consensus that survives a genuine independence audit is real evidence
— the audit's job is to license it, not to veto everything. What it
refuses to license is the feeling of weight: five people believing
something is one fact about five people; five independent channels
pointing somewhere is a fact about the world.

Provenance: the r5 false floor; the r6 triple endorsement (n=1
disguised as n=3); the r7 relay opening, where one inherited claim
was correctly treated as a claim.
