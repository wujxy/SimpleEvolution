# assumption_inversion — the counterfactual of the defaults

Load this when generation keeps returning the same direction: the
defaults are doing the generating. This is not assumption-audit
(which asks whether an assumption is right) — inversion asks what
opens if it is deliberately wrong.

## The inversions

Apply mechanically, one per line of inquiry:

- fixed → variable, and variable → fixed
- local → global
- deterministic → stochastic
- optimize → eliminate
- estimate → measure
- reconstruct → classify / retrieve / approximate
- constraint → objective, and objective → constraint

The deepest form targets the level, not the flag: "constraint A must
hold" inverts to "A is free, and the thing that must actually be held
is the deeper quantity B underneath it". Most false walls are A-level
readings of B-level constraints.

## Reading the inverted world

An inversion is cheap to hold in the head and expensive to ignore:
ask what the problem looks like if it stands, whether any known
result already contradicts the default (a counterexample is an
inversion that happened), and which single observation would make the
inverted world live or dead. Inversions that survive one look earn a
seat; the rest cost a paragraph.

Provenance: Co-Scientist's iterative assumption identification and
evolution operators; the r6 wall (a budget read as a prohibition was
an uninverted assumption).
