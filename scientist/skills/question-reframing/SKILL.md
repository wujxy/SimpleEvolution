# question_reframing — the question is the lever

Load this when answers stopped improving — effort continues, results
repeat — or when a question arrived already answered (a
predecessor's memo, a tool's framing, a field's standard phrasing).
The highest-leverage move at that point is not a better answer to the
standing question; it is a better question.

## The rewrites

Take the current question and systematically try its neighbors:

- "How do we make X faster?" → "Why is X needed at all?"
- → "What determines how many X there are?"
- → "What information is X estimating — and can that information be
  obtained another way?"
- → "What would make X irrelevant?"
- → "What is the actual scientific objective behind X?"

The same move crosses domains: "why did the nonlinearity drift?"
becomes "which detector-response degrees of freedom could produce
this observable's change?" — one phrasing hunts a culprit, the other
enumerates a mechanism space.

## Inherited questions

A question that arrived pre-answered gets rebuilt from current facts
before it earns work: strip the predecessor's framing, restate what
is actually wanted and what is actually known, and only then decide
whether the standing question is the right one. Most inherited
questions are right; the audit is cheap and the exceptions are
decisive.

The test of a reframe: the research space looks different afterward.
If every existing plan still applies, the question didn't move.
