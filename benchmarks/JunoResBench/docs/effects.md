# JunoResBench — 完整效应清单 v2

> **耦合 v2 增量（2026-09，归档）**。v2 出题（隐藏世界 IBD 类正电子、
> 波形-only 单输出 E_rec、JUNO 曲线 R@1MeV ≤ 3%）对正向链做了如下机制
> 升级；本文其余部分是 v1 效应清单，作为历史参考保留。
>
> **保留并升级的机制（默认开启）**
> - 带电粒子多步输运：动能按 5% 分数细分、2 keV 截断，逐步记录
>   位置/时间/沉积能/中点动能/局部 dE/dx/步长（`stopping_power.py`，
>   `DepositionSteps`）。
> - 局部 Birks 淬灭：按步 `dE/(1 + kB·(dE/dx))`，kB = 0.012 cm/MeV。
>   低能步 dE/dx 大 → 可见份额低——v1 的事件级全能区 quench/nl 缩放
>   已从权威路径删除（`nl_corr` 钩子不复存在）。
> - 湮灭 γ 次级：正电子事件 = Ek 沉积 + 两个 511 keV γ 的
>   Compton/光电/次截断链，空间上与主径迹分离。
> - 闪烁产光：逐步 Poisson（不再是正态取整）；Cherenkov：按步长 ×
>   (1−cos²θ)、中点 β，与闪烁光分别产生。
> - 光学与电子学：trace 光学（波长相关、吸收/再发射、散射、边界、
>   时间）与 SPE/暗噪声/数字化电子学沿用 v1（waverec 快照不变）。
>
> **明确排除的机制**
> - 事件级经验分辨率涂抹——v2 禁止在物理阶段之后补涨落；
> - 正/负电子 stopping power 差异——低于 v2 保留效应阈值（见
>   `stopping_power.py` docstring）；
> - 评估期 Geant4——生成离线一次完成，评测只做重建。
>
> **表出处与限制**：`stopping_power.py` 的 dE/dx 表是合成 LAB 类
> 连续慢化表，形状对照公开 ESTAR 有机材料曲线（5 keV–20 MeV 共 12
> 个对数插值节点）；它不是真实 JUNO 材料库，数值参数不复制真实探测器。

**定位原则**：toy MC 的目标是在资源约束下**尽可能逼近 full MC**。
默认状态 = 所有一级、二级效应全部开启。排除任何效应必须同时满足：
(1) 复原成本高（逐光子输运级、逐粒子输运级），且
(2) 对能量/位置分辨率的贡献明显小于一二级效应。
"故意做简单"是不对的——是"不得不在三四级效应上做简单"。

评价基准：σ_E/E ~3%/√E @1 MeV（~1500 pe），顶点分辨 ~10 cm 量级。
任何对 σ_E/E 贡献 ≥0.1% 或对顶点分辨贡献 ≥1 cm 的效应都不应默认缺席。

## 0. 物理过程完整梳理

```
E_true (粒子动能)
  │  A. 能量沉积阶段
  ├─ A1 粒子输运与逐步 dE/dx        (e/γ/p/α 各不相同)
  ├─ A2 能损涨落 (straggling/δ射线)
  ├─ A3 部分逃逸 (γ escape, e 射程, 边界效应)
  ├─ A4 e⁺: 湮灭 γ (+1.022 MeV), o-Ps 形成 (54.5%, τ=3.08ns), 3γ 分支 (2.2%)
  ├─ A5 γ: Compton 多次散射 → 多作用点、顶点弥散
  ├─ A6 多重散射 (位置弥散)
  │  B. 闪烁光产生阶段
  ├─ B1 光产额 LY = 10168 /MeV
  ├─ B2 发光统计涨落 σ=√N (ResolutionScale)
  ├─ B3 Birks quenching (kB₁, kB₂, dE/dx 依赖, 粒子依赖)
  ├─ B4 Cherenkov 光 (阈值, ~1/√E 角锥, 产额因子 0.517, 谱不同)
  ├─ B5 粒子依赖时间谱 (e/α/p 各自 4 成分)
  ├─ B6 发射光谱 (发射波长分布)
  ├─ B7 低能区非线性 (<1 MeV quenching 偏离)
  │  C. 光学输运阶段
  ├─ C1 LS 本征吸收 (波长相关衰减)
  ├─ C2 Rayleigh 散射 (λ⁻⁴, 42m@430nm, 改变路径+方向)
  ├─ C3 吸收后再发射 (prob~0.8, 延迟~1.5ns, 波长红移)
  ├─ C4 几何覆盖 (75%)
  ├─ C5 单管投影面积/立体角 (A_proj(cosθ)/d²)
  ├─ C6 ESR 反射膜 (R≈0.96-0.999, 提升边缘收集)
  ├─ C7 acrylic 球壳 (吸收/散射/折射)
  ├─ C8 矿油区/水区界面折射
  ├─ C9 结构件阴影 (支撑杆/校准系统, ~3%)
  ├─ C10 PMT mask/外壳遮挡
  ├─ C11 波长维度的全部上述过程 (谱过滤)
  │  D. 光子探测阶段
  ├─ D1 QE(λ) 光谱响应
  ├─ D2 CE(θ) 角向收集效率 (大角跌落: 85°→0.63-0.88)
  ├─ D3 per-PMT PDE 离散 (11-41%)
  ├─ D4 探测统计 (二项式稀疏化)
  ├─ D5 TTS 渡越时间弥散 (~4ns, 随入射角变化)
  ├─ D6 pre-pulse (光子直接打倍增极)
  │  E. PMT/电子学阶段
  ├─ E1 SPE 电荷谱 (Gauss 核心 σ_G/G≈0.32 + Exp 尾)
  ├─ E2 per-PMT 增益离散与漂移
  ├─ E3 afterpulses (MCP 1.6%, µs 延迟)
  ├─ E4 dark noise (24 kHz/PMT)
  ├─ E5 FADC 量化 (14 bit)
  ├─ E6 电子学噪声 (白噪声+频率相关)
  ├─ E7 饱和/双增益切换
  ├─ E8 读出窗截断 (慢成分丢失 → 电荷偏差, 窗随触发)
  ├─ E9 事例堆积 (多物理事例入窗)
  └─ E10 触发定义读出窗 (v4: PE 率滑窗, 已实现)
```
