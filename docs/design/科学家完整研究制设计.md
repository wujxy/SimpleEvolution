# 科学家完整研究制设计（Scientist-owned Research · 模块契约 · Research State 继承）

状态：**设计定稿（未实现）** · 2026-08-24 · 基线 tag `v0.1.0`（重构自由度：schema 可改、
行为可不保持）· 实现规格见 §8

**全部继承**；本设计只动三件事：席位租约内部做什么、模块边界、继承机制）

## 0. 一句话

把执行权下放给研究员：席位从"问一问、交一条 proposal、退场"变成"问一问、做完、
自证到底、举证结题"；executor 角色解散，claude -p 降为 scientist 手中的**全能
助手**（问 consult / 做 work 双面工具）；research state 是理解的唯一序列化载体，
以"交接文书 + 事实毕业"的方式继承给子代——**本体不过边界**，防父代锚定。

## 1. 为什么改：平级分工的三笔隐性成本

v6 的 proposer/executor 是平级接力：proposer 交 proposal，executor（独立 claude -p
会话）实现它。三笔成本，全部有 run 证据：

1. **序列化点错位**。claude -p 从来就是工具，只是握在 harness 手里，不在研究员手里。
   研究员必须把全部理解（working model、定量实测、失败史）压缩成一份 proposal 文本
   再退场；executor 拿着这份有损压缩重新理解世界、重新踩坑。序列化点应从
   "proposal → executor 指令"（一次性、有损、单向）移到"工具调用 → 工具返回"
   （便宜、可迭代、研究员直接看到结果）。
2. **真相迟到**（§11.1）。executor 执行时被告知 best=1.46M，实际树内 6.13M——不是
   executor 笨，是真相到达时研究员已经退场。裁决结果与新理解之间没有回路。
3. **双重理解**。每条 proposal 都买一次"零上下文重理解世界"。§12.2 量过这笔账：
   连续会话（理解与实现同体）$3.06 到 5.00×，议会（接力制）$12.62 到 4.79×——
   接力制的开销大头就是双重理解。

方向指引（§12.2 结论）：**连续性 + 廉价再点火 ≈ 议会性能的 90%+、成本的 1/4**；
议会的剩余价值不在速度在保障——不满足、多谱系、操作者盲区免疫。本设计把三者装进
一个系统：连续性进租约（席位自带双手），再点火进 supervisor（结题后可再买），
不满足进结题契约（举证才能收工）。

对 GPT 总结文档（docs/chat/2026.8.24.15.27）的评价：方向对——Scientist owns the
process / Claude as tool / Research State as artifact 三点成立；漏了两个要害：
**退场纪律**（§12 最强反面证据是 satisficer 早退，不是架构割裂）与**上下文蒸馏**
（工具返回必须是蒸馏物，否则自研 agent 的纯净上下文被自己的工具淹掉）。本设计以
§2.3 结题契约与 §2.2 蒸馏契约补齐这两漏。

## 2. 核心结构

### 2.1 角色与边界：研究/裁决之界

旧的界画在"想/做"之间（proposer 想，executor 做）——错位。新界画在**研究/裁决**
之间：

| | scientist（原 proposer） | supervisor | harness（tree） |
|---|---|---|---|
| 是谁 | 研究员，戴透镜入席 | 出钱人（PI） | 世界账本 + 裁判 + 出纳 |
| 拥有 | 完整研究：理解 → 设计 → 实现（经助手）→ 自证 → 结题 | 研究资源定价（节点 × 透镜） | 真相：gate/bench/bit-identity；准入；生命期执法 |
| 不做 | 裁决自己（自测是导航不是裁决） | 提方案、评实验 | 造世界观（各 agent 自己造）、替谁咀嚼 |

不变的东西：透镜三件套、谱系查重、诚实 quiescence（untried 耗尽才是程序完成）、
supervisor 决策 schema（`seat_purchases`）、integrator 主干整合——全部照旧。
**变的只有席位租约内做的事**。

### 2.2 助手（claude）：问与做的双面工具契约

claude 内化为工具后远不止写代码——它是席位门下的**全能助手**：学生怎么用
claude，席位就怎么用（查不懂的、讨论不确定的、动手干活、交付前请人挑刺）。
两面调用，契约不同：

**问（consult）**——不动世界，只动脑：
- `consult(question, context, read=node|lab|none)`：查不懂的（领域知识、库语义、
  域外先例——claude 自带 web 检索与子代理，**通用工具外购不自制**：web search
  之类不再给自研 agent 逐个接线，一律经此通道）；讨论不确定的（**辩论**：亮出
  假设，点名要反驳而非要附和）；交付前审查（让另一双眼睛挑 diff 与自证的洞）。
- 返回同为蒸馏物；raw 落盘。consult 结论一律进 **belief 通道**（署名来源 =
  助手，非 verified——裁决权不变）。

**做（work，原 workman 语义）**——席位有一间**实验室**：从被买节点 SHA 开出的
可写世界（git worktree；挂载/快照/终局回放机械收编自 `run_cont_agent.py`——
真金白银验证过的东西不留 scripts/）：
- `run_workman(instruction, mode=continue|fresh, budget)`。continue = 实验室主世界
  上继续干（默认；世界持久、会话可续）；fresh = 一次性副世界做侧实验。返回蒸馏物
  `{status, world_sha, diff_summary, self_report_digest, 关键数字}`。
- **快照与交付物**：harness 对实验室做侧链 commit（机械照搬 §12）；交付物 =
  实验室某时点的快照 SHA。
- **资源记账**：work 占核进**统一资源账**（席位在飞 + work 占用 + 评测占用
  合并；§12 core-9/11 内存带宽竞争的前科）；超卖由 harness 拒绝（执法不做主）。

两面共同的铁律：
- **蒸馏契约是成败细节**：raw transcript 永不进研究员上下文，工具返回超过蒸馏帽
  = 亲手淹掉纯净上下文。
- **记忆权威**：research state 是唯一记忆载体；助手会话可续（resume）只是性能
  优化，不是记忆通道。
- **判断权在席位**：助手是放大器，不是持剑人——透镜、方向、何时信何时疑，都是
  席位自己的事。已知新风险：**oracle 同质化**（各席位问同一个强模型，答案把
  透镜多样性洗成 claude 的默认剧本——G10 从工具的后门回来）。缓解：consult
  记台账（各透镜问了什么、采纳率——离散度可测）；提交自检加一问"哪些关键判断
  来自助手、你为何采信"；反锚定的既有执法（提交再锚定 + 透镜自检）对助手输入
  照常生效。

### 2.3 租约 = 研究项目：三种出口

席位租约从"恰好一条 proposal 或空备忘"改为"一个研究项目"，时间 / token / work 次数 /
consult 次数四重预算封顶。三种出口，全部前置校验**已登记 ≥1 条 research state**（v5 蒸发式
退场 guard 的泛化）；且登记是增量的——**每个 work 周期结束必须落账一版**（写前
日志式），"调查不蒸发"从结题时刻提前到过程时刻：

1. **交付结题**：交付物 = **一个**自建自验的世界快照 SHA + exhaustion argument
   （即交接文书，§2.6）。席位负责深度、不负责分叉：内部可以多试机制、多次实验
   （全部入 experiment_log），但交付唯一——一个 SHA 延伸一个 node，分叉权在
   supervisor（买多席）。落选的已建成机制不浪费：入 experiment_log 与交接文书
   open_questions（带自测数字）——信息上行、资源决策留在出钱人；supervisor 认为
   值得就再买一席去取，继任经 pull 重建，成本有界。charter 不出现数量语言——
   "**交付你的世界**"（所有格单数，v6 纪律原样：席位只有它的一问，也只有它的
   一个世界）。
2. **空席位备忘**：透镜在此世界确无矿，指名检验过的轴（现有契约照旧）。
3. **预算断**：租约到期。已交付的 SHA 照常送裁决；未成形的理解留在 research state
   里可被继承——断点不等于蒸发。

### 2.4 裁决与回写：闭环的最后一块

harness 对每个交付 SHA 跑冻结 gate/bench（裁判权不变，自测与裁决分立）。**裁决失败
回写作者**：rejection feedback 路由回该 research state 的作者——租约若在，重开
（作者可修原世界，也可改交 experiment_log 中的落选机制——落选者由此获得第二次
机会）；若已断，记录在案供 supervisor 定价。这是旧分工"真相迟到"的结构性
补丁：裁决结果永远有回路回到能理解它的那个人。裁决通过 → 子节点诞生（照旧），
verified 证据毕业（§2.6）。

### 2.5 research state：六块

research state 是**理解在会话边界上的唯一序列化格式**，继任席位靠它重建工作模型
而无需重新推导：

| 块 | 内容 | 认知地位 |
|---|---|---|
| working_model | 机制图景：时间去哪、不变量、已排除项 | 署名意见 |
| evidence | claim + 怎么验的 + 数字 + 出处；belief 与 verified 分立 | 分拣的原料 |
| experiment_log | 每次 work 调用：意图 → SHA → 自测数字 → 判定，**含失败** | 全分辨率，留库 |
| deliverables | 候选 SHA + 相对父代的 material difference + 自验状态 | 事实（经裁决毕业） |
| conclusion | 类型（delivered / empty / cut_off）+ exhaustion（= 交接文书）+ open questions | 写给继任者 |
| provenance | 席位/透镜/episode/节点/前代 state 指针 | 元数据 |

### 2.6 继承：重著而非转发

完整研究让 research state 膨胀一个量级；子代"首层信息"若直接收本体，过杂多乱 →
路径依赖。解法是结构，不是劝告（"写干净点"）：**继承不是转发，是重著——本体不
搬家，过边界的只有两样**。三种分辨率，三种命运：

| 分辨率 | 内容 | 命运 |
|---|---|---|
| DB 账本（全分辨率） | work 调用、原始数字、失败实验、consult 记录 | 永久留库，子代 **pull**（检索工具，想查才查） |
| research state 本体 | 完整 working model、evidence、belief | 随 episode 归档，留指针，不 push |
| **交接文书**（薄层） | 死胡同地图 + 开放问题 + 署名警告 | **唯一 push 项**，harness 硬性 ≤400 词 |

- **事实毕业**：verified 证据经裁决后进子代事实块，**摘掉署名**——它已不是观点，
  是世界的状态，越多越好、不构成锚定；belief 一律留在署名层（v6 §2.3 纪律照旧）。
  "过杂多乱"的本质危害不是长，是**事实与意见混装**、子代分不清哪个是世界哪个是
  学派——毕业机制按 evidence.status 机械路由，不需要判断力。
- **交接文书 = 结题的 exhaustion argument**，不新造文书。写作对象指定为"一个戴
  不同透镜的继任者"：哪些轴我试尽了（带证据）、哪些门还开着、我的透镜问不出来但
  你的透镜该知道的、我最大的警告。以**死胡同 + 开放问题**为主体，working model
  只作署名附件（死胡同是地图，防重复劳动；世界观叙事才锚定人）。
- **反锚定机制**：三个新执法点——**带宽帽**（软 400 / 硬 600 双档，§8.4；小到
  传不下一个世界观、只传得下一张地图；全分辨率物理上过不了边界，只能 pull）、
  **毕业分拣**、**写作对象指定**；三件 v6 旧将——**署名折扣**、**透镜不继承 + 谱系查重**、**reframe
  skill 升格为继任席位开局第一动作**。
- **锚定率（运行期指标）**：子代开局方向 vs 父代 open questions 的重合度。过高 =
  锚定（子代成为父代续集），过低 = 交接失效（白写）。两个失败模式对称、可从 run
  数据计算，进透镜账本同级的事实层——防路径依赖从设计期赌注变成运行期测量。
- **首层最终定义**：子代 node 首层 = **世界事实块（harness 造，含毕业证据）+
  交付它的那个席位的交接文书**（唯一 push 来源）。同节点其他席位的 research
  state、全部实验史——一律 pull（与 v6"兄弟知识走台账"同构，推广到父节点非作者
  席位）。

### 2.7 supervisor 与诚实 quiescence：不变式 + 一个升级

决策 schema 不变（`seat_purchases`）；untried 耗尽仍是程序完成的唯一条件。升级一
处：**再买 = 再点火**。对同一节点换透镜再买一席，继任者收到事实块 + 交接文书，问
自己的问题——§12.2"廉价再点火"的制度化：不需要人工点火，不注入系统外信息。对
satisficer 的系统性回答不是更强的 prompt（§12.2 实证：显式压力改变的是到达高度、
不是停留时长），而是**再买 + untried 经济**：每个席位可以满足，程序不会。
exhaustion 声明可审计——声明的轴 vs experiment_log，对不上 = 不诚实结题，进事实层。

## 3. 模块契约（三包 · 一账本 · 一信封）

包级依赖现状不脏（proposer→simpleevo.db、experiment→simpleevo.jobs、scheduler 只
漏一根 `validate_integration_request`）；乱在两处：scheduler 上帝对象（1953 行，
~60 方法，同时给两个 agent 造世界观 + 执法 + 生命期管理）与 scientist.py 四合一
（2695 行：压缩策略 / prompt 构建 / 协议解析 / 登记）。**模块边界 = 新角色边界的
投影，一次到位**：

```
simpleevo/  = harness：世界账本 + 裁判 + 出纳
  db/           节点/实验/裁决/席位账本（唯一真相）；透镜谱系查询在此实现一次
  adjudicate/   gate/bench/bit-identity（从 experiment/ 迁来的裁决半边）
  scheduler/    纯生命期：发射/轮询/重放/预算/资源账/quiescence 执法/准入事务
                （~700 行，读起来像驱动器）
  jobs/         envelope 进程契约（已在，复用）

scientist/  = 研究主体（原 proposer 更名；executor 一词退役）
  wake/         自己造自己的世界观（从 loop.py 搬来：_proposer_payload/_seat_block/
                _world_transition/_research_state_seed 等）
  assistant/    全能助手：consult（问：检索/辩论/审查）+ work（做：claude-p 封装
                + 实验室——世界挂载/快照侧链/终局回放，收编 run_cont_agent 机械
                + experiment 的双手半边）
  memory/       记忆与检索（l2_memory 并入）；skills；prompts；席位 charter

supervisor/ = 出钱人
  facts/        自己造自己的 facts（从 loop.py 搬来：席位账本/untried/透镜战绩）
```

- **载荷构造权下放（最关键的一刀）**：scheduler 递给进程的信封只带 ID
  （episode_id / node_id / lens / 预算）；scientist / supervisor 进程各自从 store
  只读视图组装全部上下文。四重收益：①§11.1 的"payload 消费时构造"从 run 里的
  偶然美德变成结构性质（队列里只有指针，没有过时快照）；②scheduler 从 1953 行
  掉到 ~700 行；③架构变更（助手、结题）全部落在 agent 包内，不碰 scheduler；
  ④透镜谱系等纯树函数一次实现、两处消费（facts 与执法不分叉）。
- **读写权限**：scientist 写 research_states；supervisor 写
  supervisor_events / commits；harness 写 nodes / episodes / experiments /
  attempts。DB 是共享世界账本，信封传 ID、事实走 DB——两条既有通道，正式化各自
  的权限。
- **experiment/ 解散**：裁决半边（gate / evaluator / runner）→
  simpleevo/adjudicate；双手半边（agent / git_worktree / 世界挂载）→
  scientist/assistant。这恰好是本次架构改动的模块面投影。

## 4. 迁移顺序

v0.1.0 已打 tag，重构自由度全开（schema 可改、行为可不保持）；每步检查点 = 测试
全绿。

1. **清废线**（§3.1 全表）——独立、零风险，先把树清干净。
2. **模块契约落地**：载荷构造权下放；experiment/ 一分为二；scheduler 瘦身。
   检查点：测试绿 + smoke 一轮（payload 可 diff，不要求逐字节同）。
3. **架构变更**：助手工具（consult + work）进 scientist；租约三出口 + 增量落账；
   裁决回写；继承（首层/毕业/交接）。**探针 A 先行**（§5）。
4. **schema 与工具链**：research_states 扩块、cognitive_transformations 弃、
   check_seat_v6 / plot / ablation driver 适配（旧 run 数据只读兼容）。

## 5. 探针（先行）

**探针 A（编排能力）**：冻结一个真实节点（xsbench root），完整研究模式，3 采样，
生产模型通道。测的是本设计最大的经验赌注——低 effort 研究员指挥强工具的天花板：
首交付物周期数、交付 gate 通过率、token 成本曲线 vs 连续臂轨迹（§12.2 的 $/增益
曲线直接对照）。判据：$/增益不明显劣于连续臂 → 放行全量；明显劣 → 定位（蒸馏帽？
指令质量？预算切分？），不硬上。附带观察：consult 使用模式——各采样问了什么、
采纳率、辩论是否真在要反驳而非要附和（oracle 同质化与辩论质量的初判）。

**锚定率**：不入探针，作运行期指标，首测于第一个正式 run。

## 6. 风险与开放问题

1. **满足型退场**（最大风险，§12.1/12.2 实证）：自研研究员是否比 claude -p 会话
   更能熬，未知。缓解：结题契约 + 再买 + exhaustion 审计。诚实边界：这是本设计
   最大的经验赌注。
2. **编排天花板**：deepseek-v4-flash effort=low 驱动强工具，研究员的判断质量 =
   工具链天花板。探针 A 就是它的裁决。
3. **上下文污染**：蒸馏帽失守 = 纯净上下文死亡。蒸馏契约进验收单。
4. **席位经济学变化**：席位变长变贵（实验时间进席位），4h run 的 33 席位 episode
   → 预计十几个完整研究席位。广度靠透镜质量与 untried 集合撑；接受、观察。
5. **oracle 同质化**：各席位共用同一个强助手，检索/辩论的答案可能把透镜多样性
   洗成 claude 的默认剧本——G10 从工具的后门回来；伴随**判断外包**（低 effort
   研究员对强助手照单全收）。缓解（§2.2）：consult 台账按透镜分列 + 提交自检
   加问 + "要反驳不要附和"的辩论教学。
6. **开放**：交接文书软硬帽档位（400/600）够不够（运行期调）；助手会话续用
   （resume）的实际收益。

## 7. 决策记录（含被否决方案）

| 决策 | 结论 | 否决的替代与理由 |
|---|---|---|
| proposer/executor 关系 | scientist 拥有完整研究；executor 解散为全能助手（consult/work 双面工具） | 平级接力：序列化点错位、真相迟到、双重理解（§1 三笔账） |
| 边界位置 | 研究/裁决之界（harness 独占裁决） | 想/做之界：割裂研究上下文，正是本次要修的对象 |
| 模块边界 | 按新角色投影；载荷构造权下放进 agent 包 | 先化妆式拆分再改架构（文件摸两遍）；先改架构后拆分（新东西长进上帝对象） |
| research state 继承 | 交接文书 + 事实毕业，本体不过界 | 本体直传：带宽无界 + 事实意见混装 → 父代锚定 |
| 交付粒度 | **恰好一个 SHA、延伸一个 node**（v6 所有格单数纪律原样保持；落选机制经 log+交接+再买回收） | 多 SHA 各成子节点：分叉权漏回席位、绕过 supervisor 定价（购买:产出比失恒）、多子共享一份与各自世界不对应的交接文书 |
| 裁决失败 | 回写作者、租约重开 | 丢弃（旧默认）：真相迟到，研究蒸发一半 |
| claude 工具定位 | 全能助手：问（consult：检索/辩论/审查）+ 做（work：实验室）双面；**通用工具外购不自制**（web search 等经 claude，不逐个接线） | 仅编码执行器：浪费检索/辩论/审查能力，且逼自研 agent 逐个自制通用工具 |
| satisficer 对策 | 再买 + untried 经济 + exhaustion 审计 | 更强的 prompt 压力：§12.2 实证改变的是高度不是时长 |
| 行为保持 | 不要求（v0.1.0 已 tag 归档） | 逐字节 payload diff：代码干净优先，基线已可追溯 |

## 8. 实现规格（紧凑交接）

### 8.1 schema（加性为主，cognitive_transformations 除外）

- `research_states` 新列：working_model(text) / evidence(json) / experiment_log(json)
  / deliverables(json) / conclusion(json：type、exhaustion、open_questions、
  handover) / revision(int) / lease_id；增量 upsert（每 work 周期 revision+1）。
- `episodes` 新列：conclusion_type / concluded_at。
- 新表 `resource_ledger`：席位在飞 / work 占用 / 评测占用的统一资源账。
- 弃：`cognitive_transformations`（数据保留，代码删）。

### 8.2 助手工具（consult / work）

- `consult(question, context, read=node|lab|none) → {answer_digest, sources}`：
  不动世界；claude 自带 web 检索与子代理（通用能力外购）；蒸馏帽同 work；raw
  落盘 `runs/<run>/assistant/<call_id>/`；**consult 台账**（问题摘要、采纳与否、
  token，按透镜分列——oracle 同质化的测量面）。
- `run_workman(instruction, mode=continue|fresh, budget) → {status, world_sha,
  diff_summary, self_report_digest, metrics}`；蒸馏帽：diff_summary +
  self_report_digest 合计 ≤300 词（常数可调）；raw 落盘同上；资源占用记账；
  实验室 = 节点 SHA 开出的 worktree + 侧链快照（run_cont_agent 机械）。
- 预算：时间 / token / work 次数 / consult 次数（consult 计入 token 家族，次数
  单列防刷）。

### 8.3 席位 charter 改动

职责段改为：investigate → **build（经你的助手）→ self-verify → conclude**；
"维护你对这个世界的理解，**交付你的世界**，举证你的结题"（所有格单数）。数量
语言仍零出现；空席位契约照旧；reframe = 继任席位开局第一动作。

**助手教学块（必入 charter，一段为限）**："你有一位全能助手：不懂的问它（它
可联网、见过更广的域）；不确定的与它辩——亮出你的假设，点名要**反驳**而非
附和；动手的让它做（你的实验室）；交付前请它审你的 diff 与自证。判断权永远
在你：它是你的放大器，不是你的持剑人。"

### 8.4 交接文书契约与硬交付重试纪律（harness 执法）

- **双档帽**：prompt 告知 ≤400 词；harness 机械上限 600 词——留余地，"写超了"
  先是违规感，被机械拒绝前还有空间。必含：dead_ends（带证据指针）/
  open_questions（**含建成未交付的落选机制及其自测数字**）/ warning（署名）；
  模板锚定写作对象（"致继任者：你的透镜与我的不同……"）。
- **硬交付必带重试**：超硬帽 / 必含块缺失 → 打回重写（带具体违规原因），有界
  重试（默认 2 次；v6"0 state 的 abstain 重试一次后放行"的同款防死循环）。最终
  仍不合规 → **降级不废弃**：交付物照常送裁决——**SHA 延伸 node 的权利与文书
  合规解耦**；文书记 non-compliant，子代首层退化为指向父代 research state 的
  pull 提示。
- 此纪律适用于**一切硬交付点**（交接文书、交付 SHA 缺失/不可解析、无落账
  结题……）：软标准进 prompt、硬标准进 harness、硬违规走"打回-重试-降级"梯子，
  任何一步都不把整场研究作废。
- 毕业路由：evidence.status=verified → 子代事实块（机械路由）；belief → 不出
  署名层。

### 8.5 验收单

1. scheduler <900 行，grep 不到透镜三件套 / prompt 文本 / facts 构造（只剩调用）。
2. 信封只含 ID；scientist / supervisor 包各自重建上下文（单测：同 ID 重建）。
3. 助手两面（consult/work）返回 ≤ 蒸馏帽；raw 落盘可寻址；资源账含 work 占用；
   consult 台账在案；charter 含助手教学块（问/辩/做/审 + 判断权声明）。
4. 无 ≥1 条 research state 不得结题（打回重试，单测）；交接文书双档帽：>600 打回、
   重试有界、降级不阻塞交付物送裁决（单测）。
5. 裁决失败回写作者、租约重开，可改交落选机制（单测）。
6. 子代首层 = 事实块 + 唯一 handover；全分辨率材料仅 pull；锚定率可从 run 数据
   计算。
7. 一租约一交付物一子节点；落选机制在 experiment_log 与交接 open_questions
   可追溯；谱系 burned 语义照旧。
8. 探针 A 完成，读数在案。
9. 清理表全勾；旧 run 数据只读兼容（check_seat_v6 对 v0.1.0 之前的 run 仍可跑）。
