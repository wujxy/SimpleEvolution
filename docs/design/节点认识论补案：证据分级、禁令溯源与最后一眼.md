# 节点认识论补案：证据分级、禁令溯源与最后一眼

状态：**决定版（2026-09-03）**。本文经历了两稿：初稿给三病灶各开一科（分
级印章／溯源制／保鲜层两问），被否——"谁有病医治谁"，三次类型违例被当成
了三种病。决定版回到根因：**r9 的信息系统里"事实"与"论断"是同一种东西
（简报里的一句话），信息只经人转述、无处落档**。修复不换架构，只补信息层
的三件东西（§3），全部已落地（scientist 包，JRB 线同享）。

关系：《演化实验室设计》（population 主案）不受影响——那是架构轨；本补案
是信息轨，先在现行 sci+席位架构上兑现，population 轨将来直接继承（record
即 Shared Record 的第一块砖）。

---

## 1. 为什么架构不动

r9 尸检结论：每个器官都健康——sci 的路由/复算/提问逐拍合格（003 简报甚至
点名了 r3 的致胜候选并明示 faithful 替换安全）、executor 测量纪律合格、
席位按合同履职。病全在信道上，动器官等于给心脏没病的人搭桥。同一框架
（supervisor 分配、executor 连续干活、卡住时会诊）r9 拿到 2.54×，隔壁
singleton 3.76×——差别不在编制，在信息怎么写、怎么流。

一句话能劫持全队的充要条件：**它改变所有人的行动，却不支撑任何人的工作**
——检验它的收益无人认领（揭穿不加分），遵守它的成本隐形（错过金矿看不
见）。r9 的 "per-call floor is reached" 正是如此：challenger 按它出题、
reviewer 按它验状态、executor 007/008 在它画的圈内服从；无人的产出需要它
为真。三重背书、5.4 小时零检验。

三病灶是同一类型缺失的三次发作：

| 病灶 | r9 实况 | 类型违例 |
|---|---|---|
| A 仪表故障被当成世界判决 | "gprof 没抓到 gmon.out → concluded floor" | "没测到"（事实）冒充"到头了"（论断） |
| B 教义逐跳单调收紧 | spec 门 → "Do not approximate" → "explicitly forbidden by brief" → "bit-identical only" | 论断（sci 的风险判断）穿了法律的语法 |
| C 半步之差信念先到 | executor 亲手 precompute 了 dmu/fdmu，却没缓存 exp(-fdmu)——r3 的 `522b430` 就是这半步 | 宣布"没有了"之前没有清点库存 |

共同点：发生时不可见——gprof 摔了藏在 35MB 轨迹深处，收紧发生在两次转述
之间，半步没有语言能描述。**判断没问题，判断的输入是盲的。**

## 2. 修复的形状（先于条文）

三条规则，都可以写成文件格式和行为约定，不动任何编制：

1. **结论落文件，不过人。**重要结论只有一个家：公共档案。agent 之间传递
   的 prompt 里只准出现问题和档号，不准复述别人的结论——失真不是被小心
   避免，是不可能发生。
2. **写结论标成色。**事实（跑出了东西，附复现）/ 没测到（仪表失败也是合
   法结果）/ 推断（从事实猜的，附最便宜的反驳实验）。表格加两栏作者自
   填，无准入无执法——裸推断看得见地廉价。
3. **要用先验。**下一个要把工作盖在推断上的人负责先跑检验法：跑赢了收
   益归他，跑输了省一天。不设专职挑战者——r9 的 challenger 任务成败与那
   句话真假无关，所以用分析答了该用实验答的题还给了 CONFIRM。

## 3. 落地（已实现，2026-09-03）

| 物 | 落点 | 内容 |
|---|---|---|
| **档案库** | `.scientist/record.jsonl`（ledger.note_record，收集时自动追加） | 每个 engagement 一行可引用记录：REC-001…，署名（role+call_id）、报告、成色、检验法、证据、工作区指针。digest 回执带 record_id |
| **章程四条** | collaboration.py `_LAB_RECORD_BLOCK`（全部席位 prompt + 续用 prompt 常驻） | ①结论落档不落对话 ②引用不复述（挂不上 spec/档号的限制性表述=同事建议）③要用先验 ④没测到如实记 |
| **行为准则** | prompts/scientist_code.md（sci 系统提示常驻，不可被 spec 覆盖） | 见 §4 |
| **digest 契约** | `_CLOSING_CONTRACT` 增两栏 | `claim_grade`（measured/not_measured/inferred）+ `falsifier`（推断类必填最便宜反驳实验） |

要点：档案库是环境不是管理者（合宪：harness 提供环境不插手决断）；席位
零行为改动即自动落档（harness 在收集时归档）；sci 的 research_memory 本就
在 `.scientist/`（席位可读），补上的是席位侧的对称物。

## 4. 科学家行为准则（十四条，溯源在案）

给 sci 的不是防 r9 复发手册，是"科学家"这个职业四百年的行为准则——我们
的立法也守溯源法，每条挂真实出处：

| 组 | 条 | 溯源 |
|---|---|---|
| 面对世界 | 1 测了才算数 / 2 没测到≠"没有" / 3 反常先查装置 | 实证科学第一律；测量诚实；实验员本能 |
| 面对自己 | 4 观察与解释分栏 / 5 不越数据半步 / 6 主张自带死刑 / 7 最易骗的是自己 | 实验记录本两栏传统；过度声明之罪；Popper 可证伪；Feynman 1974 |
| 面对他人 | 8 不轻信任何人的话（含三前的自己）/ 9 转述如引用 / 10 规矩挂出处 / 11 没落档=没发生 | 皇家学会会训 Nullius in verba（1660）；Merton 普遍主义/共有性（1942）；引用规范；Feynman 1974（存疑细节必须全数交代） |
| 面对结论 | 12 失败也是结果 / 13 清点库存再宣布没有 / 14 怀疑是职责 | 负结果发表（可复现性危机教训）；穷尽性纪律；Merton 有组织的怀疑 |

对 r9 的覆盖：gprof→floor 缺 2+14；"Do not approximate" 棘轮缺 9+10；
差半步缺 13；三重背书无人跑实验缺 8+14；judgment 无成色缺 4。**五处失
误，没有一处落在准则之外。**收尾自问句随准则常驻：哪几句是世界说的哪几
句是我说的？今天哪个结论没附死刑？我在希望哪个结果为真？

## 5. r10 验收读数

同架构、同任务、同门，只加这三件。及格判据全部可从日志与档案测：

- **假主张存活时间**（主指标）：floor 类推断从出生到第一次被检验。r9 基
  线 ≈5.4h、零检验、三方背书寿终正寝；及格线：观察窗内至少一次检验尝
  试（最理想即 r3 式走穿）。
- **三随行率**：被转述的推断类结论中，成色+限定+检验法随行的比例。r9 基
  线≈0（gprof 从句三跳归零）。
- **无档号禁令数**：sci 产出里挂不上 spec 条文号的"不许 X"。r9 基线≥2。

## 6. 明确不做

不设执法（违反只在档案与 prompt 留痕、在读数显形——改行为用信息不用执
法）；不加编制（无专职挑战者、无谱系学家）；不修串行空等（效率问题另
案，与保真无关）；不动 JRB 线部署（行为层自动继承，属预期）。
