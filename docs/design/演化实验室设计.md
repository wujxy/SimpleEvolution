# 演化实验室设计：把研究权让渡给 autonomous researcher population

状态：定稿基线（2026-09-03）。来源：r9 行为审计 + r3 对照实锤 + 与提案 agent 的对表（docs/chat/2026.9.3.12.45）+ 本会话 review 四点与认知席位补案。**同日二次收缩（docs/chat/2026.9.3.14.23）：认知席位机制退出 v1（§7.3 后置），peer conversation 成为主变异通道；researcher 长命原则确立。**

取代关系：《科学家完整研究制设计》的中心脑形态（scientist 亲自研究 + 席位咨询）退役。《世界三区设计》《席位工作区重设计》《科研技能层》的全部零件保留复用。本设计是 scientist 与 simpleevo 的一次 combine：底座是 SimpleEvolution 的 node/evolution 账本，身体是 coding-arm 的会话机器，撤掉的是中间那颗必须串行的脑。

## 1. 证据与动机

四个run的读数钉死了方向：

| 证据 | 读数 | 含义 |
|---|---|---|
| r3-coding（singleton，ds-v4-flash low，3.5h） | **3.76×**（≈244ms），四门 PASS | researcher 本体已足够强；单会话=当前冠军 |
| r9-scientist（sci+9席位，medium，7.6h） | 2.54×，74% wall 空等 | 中心脑塌缩成串行咨询；launch 后 3 秒即 wait |
| r9 假地板 | executor 宣称 floor≈355-360ms，challenger 机制性"确认"，reviewer 复核 | 三重背书产出假地板——被 r3 用同类 bit-exact 微优化走穿 |
| PI-team-v3（人当 PI + 4 席位并行） | 2.57× vs coding 2.29× | 存在证明：population + 分配能赢 singleton，输的是机器 PI 的工作形态 |

诊断：r9 的两个症状（席位工具化、sci 串行）是同一个协议的两端。任务委托制下，中心分解完任务就无事可做（→wait），辐条除任务外无处可站（→工具）。立场是被实例化的（独立 context/workspace/trajectory），不是被 prompt 的——席位制想在进程树里模拟同事，只有真有独立身体才成立。

## 2. 核心主张

> **SimpleEvolution = World + Population + Shared Record + Evaluation + Evolution。**
> Claude Code 负责科研；SimpleEvolution 负责让很多 Claude Code 处在一个能共同进化的实验室里。

两条铁律贯穿全设计：

- **聪明的变异，愚蠢的选择。**变异可以聪明且有立场（错被选择过滤）；选择必须蠢且不可腐蚀（evaluator + 预算数字，没有上一层来纠错）。r6/r9 的病都是"聪明的选择"。
- **事实共享，认知不同步。**公共层只放可再裁判的对象；worldview 永远不成为别人的前提。

## 3. 结构

```text
                         Supervisor (v1: 纯代码策略 + 人断点)
                population / allocation / eval queue / 钩子
                            │
             ┌──────────────┼──────────────┐
           Node A         Node B         Node C      (冻结 world, git SHA + 客观值)
             │              │
       ┌─────┼─────┐        │
      R1    R2    R3       R4…               (researcher: 独立 workspace/context/trajectory)
       │     │     │        │
       └── findings / bets / seeds' / dissent ──→ Shared Research Record
             │
        candidate worlds (side commits)
             │
        evaluator (独占串行队列, 只认其读数晋升)
             │
          child nodes
```

变异单位从 Proposal 变成**完整 autonomous research trajectory**。Proposal 不再是演化的核心中间实体——它降格为谱系学家产出的一种对象（bet）。

## 4. Researcher（研究员）

- 第一版本体固定：Claude Code（经 coding-arm 会话机器驱动），不重造 ReAct loop。比较的干净性由此保证：`1 × CC` vs `N × CC + Shared + Evolution`。
- 每个 researcher 拥有：独立 workspace（node 的 fork/lease，复用 assistant/lab.py 的 worktree + snapshot 纪律）、独立 context、最大科研自主权（读码、profile、假设、实现、小实验、跑 probe、推翻自己、读别人的 findings、吸收别人的代码、直到 session 结束）。
- **Lab Protocol 常驻，只有四规**（写入 workspace，等价于研究员的实验室守则）：
  1. **写**：得到对同行有复用价值的结果 → publish finding 入 shared record（重要结果不留在私聊里）。
  2. **读**：准备进入明显新的方向时，先看近期新 findings。
  3. **问**：卡住或需要另一视角 → 直接找 peer 交流。**异步：发出后继续自己的活，不阻塞等待**（否则就是在同侪层重建 r9 的 wait 反射）。
  4. **组合再裁判**：吸收/合并他人代码产出的任何候选，必须重过 evaluator 才能成为 node。
- SimpleEvolution 不规定 propose→plan→code→review→reflect 之类的流程。研究员自己决定怎么研究。
- **长命原则：researcher 是长期投资，不是一次性工人。**实测教训（fresh executor 接力 250ms 无法突破地板）：交接天然耦合两样东西——framing 便宜可文本化、随交接传递；深层 code/world 认知昂贵且具身、随 session 死亡。fresh 接力的结果是继任者**又浅又锚死**。因此：
  - 默认 researcher 持续活着、持续研究；**fresh researcher 是昂贵的多样性手段，不是标准接力方式**。
  - 物理会话以验证过的 4h coding-arm 单元为周期；长命 = 逻辑连续（workspace + notebook + 谱系不变）。
  - 跨会话只许**自我交接**（自己给自己写下一程的开场）；**他人策展的交接非法**——那是把一个大脑的 framing 变成另一个大脑的 premise。

## 5. Node 与谱系

- Node = 一个成立的 world state：`git SHA + objective（如 ms/evt）+ gates + parent`。Node 本身冻结。
- 多 researcher 从同一 Node 出发，各自 fork，不共享 mutable workspace。任何人的实验先发生在自己的世界。
- 谱系保持简单树：`parent(C3)=C1`，同时记 `incorporates=[C2]`（横向吸收的来源）。world lineage 用树保可解释，research provenance 记多来源。
- **Node 晋升不重启 researcher**：researcher 随自己产出的 world 持续跨 node 研究；是否吸收别人的 promoted 线（checkout/incorporates）由 researcher 自己决定。Node 是世界谱系，不是 agent 生命周期。
- 晋升唯一通道：独占队列的 authoritative eval 通过（见 §9）。

## 6. Shared Research Record（三视图 + 四对象）

| 层 | 内容 | 可见性 |
|---|---|---|
| Shared Record | findings / bets / seeds' / dissent，全部署名带 provenance | researcher 与 supervisor 可读 |
| Researcher Notebook | 自己当前的理解、在追什么、未验证的判断 | **生前私有，死后归档**（归档后谱系学家可读——实验记录本的惯例） |
| Supervisor View | population 水位、预算、分配记录 | 只服务 allocation，不是公共真理 |

**Finding**（事实层）：
```text
node: N17  |  agent: A3  |  ts
tried:    Reduced Minuit maxcalls to 40.
result:   −18% speed, CONSISTENCY fail.
finding:  只排除该激进设置，不构成"调用数不可降"的证据。
code:     commit abc123
```
别人可以信、疑、复现、扩展、忽略。它不是必须正确的结论。

### 消息与 finding 分离（两条通道）

- **message = 临时对话**（问、辩、挑战、通报 breakthrough、商量 merge）——不进公共记录，不要求同步。
- **finding = 实验室公共记录**——重要结果最终 publish，不能只活在 A→B 私聊里（否则 B 一死知识就丢）。
- 同步通道 v1 优先用 Claude Code 自带的跨会话消息。**验证项**：确认它在长命 headless 会话形态下可用；fallback 是 record store 里的 per-agent 收件目录——同一文件通道、零新机器，只是消息对象不进 finding 的公共索引。
- Record 是**实验室基础设施，不是 world 状态**：挂 world git 之外的独立通道（append-only jsonl + 署名 + provenance），否则 findings 会混进快照、污染谱系。隔离宪法新站位：researcher 的世界里只挂本 lab 的 record，别的一概看不见（sibling-leak 的老家）。

## 7. 变异体系（v1：只有两档）

一条语法不变：**只定角度，禁止写预期结论**（goal 纯净法适用于一切 seed 类对象）。

### 7.1 暖变异（主循环，近零成本）：peer conversation

多个长命 researcher 本身就是不同的脑，且都已付清理解代码与实验环境的成本。A 卡住时最便宜的变异是直接找 B/C 谈当前 framing：

> "我做到 250ms，怀疑剩下的是 Minuit call-count floor。你从你的路线看，有没有反例或完全不同的解释？"

同行基于各自真实 trajectory 给出不同 evidence、反例、新 framing、可复用代码、A 没看见的方向；A 自己决定是否接受，回到自己原 session 继续。不需要 judge，不需要正式 debate protocol。**Peer conversation 是最便宜的 cognitive mutation。**

初始差异（可选）：入住时附一条静态 seed（= 现有 20 卡 discovery 档原样重定位：assumption-inversion、question-reframing、representation-shift、search-the-negative-space、wall-foundation-attack…零新词汇）。

### 7.2 冷变异（低频逃生，显式计价）：fresh researcher

全新 researcher 有真实成本（上手时间 + token + 丢失前人对项目的理解），只在**数值触发**时投放：多样性仪表显示集体收敛 + 全 population 分数斜率趋平 + 零跨轨迹借用事件，持续一个观察窗。触发是水位表数字，不是判断——"偶尔 fresh"不能是感觉。

### 7.3 后置候选（不入 v1）：谱系学家

proposer/challenger 镜、`seed'/bet/dissent` 三对象、informed 配额、饱和钩子——全部后移成 future candidate。两个原因：

1. 没有证据表明 population 需要这套机制，且它重新引入"harness 帮 researcher 科研"的风险；
2. 谱系学家是**代际机构**，而长命研究员取消了代际——它的产出本该由新一代 fresh researcher 消费，如今没有消费者。

**再入条件（记录在案）**：真实 run 中 peer communication + findings 仍走不出 collective false floor（r9 假地板回归用例失败），届时以真实失败为存在理由重启。红线若重启仍然全部有效：产出只落 record 不进开场白；可检验性是入池条件；配额上限保底压。

## 8. Supervisor（v1：纯代码）

职责窄到可以不是 LLM：**node allocation / research diversity / resource allocation / world evolution / population transition**。它管"哪里值得放 researcher"，绝不管"进去以后怎么研究"，也不写任何 researcher 的简报。

- **分配键 = 记分牌数字**：ms/evt、gates、token 消耗、谱系多样性。findings 的叙事只给 researcher 互相看——分配被最会写 finding 的人劫持，就是 r6 三重背书在分配层重演。
- **钩子（确定性）**：evaluator 过→建 node；预算尽→收 session；多样性仪表 + 分数斜率 + 零借用事件（持续观察窗）→投放一个 fresh researcher 名额（冷变异，§7.2）。不触发任何认知流程。
- **水位表**：席位占用/空闲、wall/token 预算余量、每 node 活跃轨迹数——管理者只能管理它看得见的水位（r9 塌缩的半个原因就是宽度不可见）。
- **人只在断点处上手**（PI-team-v3 赢的形状）。LLM 判断（"哪个 node 的前景超出数字所示"）等数字策略证明不够再进——那是 v2 的事。

## 9. Evaluator 与独占队列

评测仪是独占资源：SPEED_MS 是墙钟，4 个 researcher 同时编译/跑 bench 会互相污染 ±1.5% 的噪声地板。

- **probe（--evtmax 10 等）**：可并发，容噪解读（小差异当平局）。
- **authoritative eval（100 evt 全套门）**：进独占串行队列；**node 晋升只认独占队列的读数**。
- eval 吞吐 = 演化速率上限，队列深度进水位表。物理实验室本来如此：四个博士后共用一条束线，排队就是日程。

## 11. 验证计划

四级消融梯（omilrec-v100 首验，同机同门）：

| 臂 | 配置 | 量什么 |
|---|---|---|
| A | r3 singleton（已有） | null：**3.76×** |
| B | 4× 独立、无共享、取最大 | 纯并行彩票的价值 |
| C | B + findings + Lab Protocol（四规） | 协作的价值 |
| D | C + supervisor 分配 + 谱系学家 + 跨代演化 | evolution 的价值 |

读数：deliver×、token/$、time-to-3.76×-等价、**轨迹多样性**（第 2 小时 N 条 trajectory 的分散度——herding 是本设计最可能的慢性病）、**peer 变异读数**（对话计数、谁在什么分数档发起、跨轨迹借用事件数——这是暖变异是否真的在发生的仪表）。

**验收用例**：
1. **r9 假地板回归**：构造 population，早期 findings 集体宣布 floor≈2.5×，看**暖变异（peer 交流）能否自己走穿**（r3 已证可走穿；走不出 = 冷变异投放的证据，也是谱系学家重启的再入条件）。
2. **D 臂及格线 = 3.76×**：演化实验室打不过 singleton 就是只换了拓扑没换本质。
3. **per-dollar**：必须赢 4× 独立彩票，不只是每场赢。
4. **bet hit-rate**：被采纳的赌注多少导致 node 改进——谱系学家自己的记分牌也是世界的，只是滞后。

## 12. 边界与第二阶段

- lab 级隔离：一个 lab 的 population 只能看自己的 record（run-by-run 宪法适用于 findings 边界，sibling-leak 教训的新站位）。
- findings 膨胀：格式小 + 定期蒸馏（distill 预算概念复用）。
- 第二阶段：JRB 型贵记分牌研究域（evaluator 吞吐低，协作层权重更高）；常驻型谱系学家（读活 record 随时出版假设）；LLM supervisor。
- 保留判断：本设计的隐含后盾是**廉价记分牌**——omilrec 的 eval 几分钟一个判决，分配错误被世界快速定价。贵记分牌领域里 supervisor 自身判断占比变大，是另一个问题。

## 13. 六句收束

1. 一个 Node 是一个冻结的 research world。
2. 一个 Node 可以入住多个完整 autonomous coding agents，各自独立 workspace/context/trajectory。
3. 所有 agent 横向共享可再裁判的对象（findings/bets/seeds/dissent），不共享 worldview。
4. 变异有三层：静态 seed 池、代际边界的谱系学家、研究员临终自 seed——全部只定角度不定答案。
5. 选择愚蠢而不可腐蚀：evaluator 独占队列 + 预算数字，supervisor v1 是代码。
6. 组合自由但继承必经再裁判：任何 merge 出的候选，重过 evaluator 才成为 node。
