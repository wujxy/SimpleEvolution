## 0. 为什么要重定义

六个任务（jrb/xsbench/omilrec × 各代）的 mount 表是沉积出来的：
`WORLD_RW="OMILRECV2/src .scientist .git build InstallArea TEMP"` 是
"当时要跑通"的手拼串，不是从"世界是什么"推导的。三张地图互不相等：

1. **世界的真实机制**：一个 git 工作树 + EROFS overlay + 若干绑定；
2. **harness 对世界的假设**：`.scientist` 放在工作树里，只因为路径方便；
3. **行动者拿到的地图**：prompt 一句"可编辑面是 src"，git 语义、
   `.scientist` 的存在、stash 会吞 untracked——一个字没说。

**2026-08-30 r2-scientist(v7) 事故**是三图错位的爆雷，不是孤例 bug：
PI 于 19:53 死于 `session/wire.jsonl` 消失（step-25 bash 的 git 级操作，
命令体随 wire 俱焚）；孤儿 executor-003 在 PI 死后无人收口又活 33 分钟，
20:26 为"测干净基线"跑 `git stash push -u -m "optimization-wip"`——
**教科书级的工程卫生**——把 `.scientist` 整个吞进 stash（法证：
transcript 340 行；`stash@{0}^3` 含 `.scientist`；`_gc_forks` 已排除
嫌疑，只扫 scratch/fresh-*）。

定性：**没有任何行动者违约——约根本没立过。** 合法 git 工作流 ×
无身份的 harness 状态，这是结构洞，补丁堵不住（四层补丁方案已被
否决：慌着加新东西去旧东西）。

## 1. 三区模型

世界的宪法只回答三个问题：什么是真理、什么是研究者的地盘、什么
是研究者本人。答案就是三个区，没有第四样东西——任何真实实验室
的结构：标定好的仪器、研究者的台面、研究者本人。

| 区 | 内容 | 执法 | 合法写者 | 一句话 |
|---|---|---|---|---|
| **冻结区** | tests/、eval 脚本、baseline/、任务说明 | EROFS bind | 无人 | 世界的物理常数 |
| **研究面** | src/、`.git`、`.gitignore`、build/、TEMP/、InstallArea | RW bind + 世界契约 | PI、受派 current 席位 | 研究者的全部地盘 |
| **私有区** | `.scientist/`（wire/session/memory/ledger/assistant） | 双挂载（§3）+ gitignore + 契约 | **仅 harness 进程** | sci 和席位的身体/大脑 |

### 1.1 私有区 = 身体（三条自明规则）

- **身体在世界里，但不属于世界**：实验台搬不走你的脑子。git、
  `rm`、stash 都够不到 mount 点。
- **可以自我感知，不能开颅**：行动者可读自己的记忆（RO 视图），
  但一切写入走器官——remember→harness 代笔、席位派遣→harness
  建档、报告→closing JSON。没有人直接手改自己的海马体。
- **器官移植有条例**：席位 fork 接收记忆的 curated 副本（笔记本的
  relevant pages）；思维流（wire/session）永不出海。现有 curation
  逻辑原样归位。

### 1.2 降级为区内部机制的旧概念（减法台账）

原四区草案里的"抛弃区"取消：build/TEMP 与 src/ 在宪法问题（谁写、
受什么保护）上答案相同，唯一差别 tracked/untracked 是 **git 的内部
机制**，不是世界分区。世界层级只说"这是你的台面"；台面上什么该
commit、什么是杂物，是研究者自己的 git 卫生（prepare 生成合理
.gitignore 作为初始默认，如同任何开发者会做的那样）。

| 删掉 | 换来 |
|---|---|
| 六任务六串手拼 WORLD_RW | 三区类型，mount 表生成 |
| gitignore 手维护（build 列了 .scientist 忘了的运气差异） | prepare 从分区生成 |
| 每任务 prompt 里"可编辑面是 src"孤例 | 一份世界契约，PI 与席位同一说明书 |
| 席位工作区模式迷宫（current/isolated/fork/lab 四套各讲各的） | 一句话："你的工作区是哪个研究面" |
| "记得保护 .scientist"清单项 | 构造性免疫，不需要记得 |

净变化为负：新增的只有两个名字（三区 + 世界契约）。

## 2. 写者地图（一个世界一个写者，落在区上）

- **冻结区**：无人写。mount 执法，六个任务零违规的历史证明"声明
  +执法"行动者吃得下。
- **研究面**：PI（亲自 apply/commit/跑 bash）+ 受派 current 席位
  （派遣契约即授权）。**并行席位各自住进独立研究面**（scratch 侧
  fork = 一份台面副本），合并回主研究面只经 PI 的手——v7 宪法
  "一个世界一个写者"在区上的表述。
- **私有区**：仅 harness 进程（器官代笔）。快照环只读拷贝。
- **世界外的 infra**：席位 claude-config 与转录（run_dir/scratch）、
  snapshots、supervisor——不属于世界，属 run 工件。

## 3. 机制推导

### 3.1 mount 表（从三区生成，取代手拼串）

```
冻结区内容        → :ro bind（现状 EROFS overlay 机制保留）
研究面内容        → RW overlay（src/.git/.gitignore/build/TEMP/InstallArea）
world/.scientist  → 同一宿主目录双重绑定：
                     /work/.scientist  :ro   （行动者的自我感知视图）
                     /state            rw    （harness 器官的写入通道）
```

三层独立执法，每层廉价：
1. **RO mount**：构造性不可写——git stash/clean、rm、重定向全数
   弹回；这是法律。
2. **gitignore（prepare 宿主侧追加 `.scientist/`）**：git 不可见
   ——status 干净、stash -u 根本不扫它；这是卫生（不承载安全性，
   因为 .gitignore 在研究面内是可变的）。
3. **世界契约文本**：诚实的地图；这是礼仪。

注意 `.gitignore` 随研究面 RW（研究者的台面配置）。身体的安全性
**从不依赖** mutable 文件——mount 是唯一的执法点。

### 3.2 harness 路径改造（最小）

`World` 增加 `state_dir`，缺省 `work/.scientist`（非容器/测试路径
零改动）；launcher 显式传 `/state`。scientist.session / ledger /
assistant / wire 全部从 `state_dir` 派生。席位 fork 的记忆播种改从
`state_dir` 取源。快照环与 supervisor 在宿主侧读 `world/.scientist`
原路径，不受容器 mount 影响。

### 3.3 孤儿收口（supervisor 侧）

席位 `start_new_session=True` 脱离进程组——python finally 没杀掉
executor-003 才有 33 分钟孤儿期。修法在 supervisor bash：agent 退出
后扫 `world/.scientist/assistant/*/proc.pid`，逐 pid 杀树。身体的
mount 免疫保证 pid 档案本身不可能再被吞。

### 3.4 状态快照（RESUME 的物质基础）

现有 src 快照环（~4min 周期）顺带拷身体：session/、memory/、
ledger/、assistant 的 manifest+digest（**跳过 raw.txt**——席位
转录在 claude-config 有真身）。wire 是 append-only JSONL，快照
撕裂尾行可容忍（重放时丢弃不完整行）。本次级别的事故从"run 死掉"
降级为"丢 ≤4 分钟"。

## 4. 世界契约（行动者收到的说明书全文草案）

进 PI system prompt 与席位 collaboration prompt，同一份文本：

> ## The world you work in
> This world has three zones.
> **Frozen**: the eval scripts, tests, baseline and task statement are
> read-only mounts. They are the constants of this world — every claim
> you make is judged here, and nothing you do can change them.
> **The research surface**: everything else you can write — src/, the
> git repository, build/, TEMP/. It is a git worktree and git is your
> main instrument: commit what you establish (a commit is the unit of
> handoff; history is how knowledge survives you), diff what you
> propose, and treat build/ and TEMP/ as disposable bench clutter —
> regenerable, already gitignored. To measure a clean baseline, use
> `git worktree add <path> HEAD` (a second checkout you delete
> afterwards) — it leaves your working tree untouched; never stash or
> clean the whole tree for measurement.
> **Your body**: /work/.scientist holds the run's memory and records.
> You may read it; it is written only through your own tools (memory,
> delegation, reports), and it is not part of the git worktree — no
> git operation sees or touches it.

席位版补一句：你的工作区（或 fork）是一个研究面；fork 里随附的
`.scientist/` 是记忆的只读副本——可读，勿写；你的产出走文末的
closing JSON。

## 6. 威胁模型表（行动者 × 合法动作 × 暴露 × 护栏）

| 行动者 | 合法动作 | 撞上什么 | 护栏 |
|---|---|---|---|
| PI bash | `git stash -u` / `clean -fd` | 身体在 untracked 区（旧世界） | gitignore（不可见）+ RO mount（不可写） |
| current 席位 | stash 测基线 | 同上 | 同上 + 契约祝福 worktree add |
| 孤儿席位 | PI 死后继续改世界 | 无人收口 | supervisor pid 扫尾 |
| 任意行动者 | `rm -rf /work/.scientist` | 身体 | RO mount 弹回 |
| 任意行动者 | 手改 .gitignore 摘掉保护行 | 误以为绕过 | 护栏从不依赖 mutable 文件 |
| eval | 写 TEMP | 抛弃物 | 研究面内部，by design |
| 快照环 | 拷贝时席位在写 | 撕裂读 | append-only JSONL 容忍 |
| RESUME | wire 尾行撕裂 | 重放崩溃 | 丢弃不完整尾行 |

**不做的事**：不给席位上命令过滤/审批（8-29 修正案刚全开工具面，
不因噎废食）；不回退弄瞎 agent 的老路；不给行动者加任何新能力。

## 7. 实施顺序（每步小，全绿再下一步）

1. prepare 宿主侧追加 `.scientist/` 进世界 .gitignore（幂等；
   node_common 一处，三任务通用）。
2. launcher 双挂载 + `state_dir` 传入；`World.state_dir` 缺省值保
   兼容（tests 全数不动为先决）。
3. 科学家包路径切换：session/ledger/assistant/wire/fork 播种源。
4. supervisor 孤儿扫尾（bash，~10 行）。
5. 快照环带身体（跳过 raw.txt）。
6. 世界契约文本进两处 prompt。
7. smoke 增门：`/work/.scientist` 写入须 EROFS、`git status` 须不
   见身体、`/state` 须可写、`git worktree add` 须可用。
8. 验收 = 事故重放：在活世界跑 `git stash push -u` + `rm -rf
   .scientist` + worktree 基线测量，三者后身体完好、git 干净。
9. r2-scientist run 目录 postmortem README（法证已归档于会话）。
10. 对齐后的世界上重发 v7 臂（r2 目录保留作案现场）。
