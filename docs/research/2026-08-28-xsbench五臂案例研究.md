## 2. 行为演化：预算钟摆四摆 → 自主交付

停机行为随 goal/budget 语义摆了四摆，根因是**内设时间墙**：任何写进上下文的预算义务都会被模型读成停机条件的一部分，与"结论义务"抢主导权。

1. **37min**（v1）：无义务文本 → 有可辩护结果即退；
2. **180min**（v3）：预算义务（"expect to spend it"）→ 有稳 foothold 仍 cut_off，80% nudge 后还在等 executor #2，handover 丢失；
3. **28min**（v4）：义务照旧 + Charter discovery 句 → 更早退出，把框内剩余领地全标"regression 或 cheat-adjacent"后判"地图已尽"；
4. **59min / 2.6h**（v5 / container-v1）：**budget 文本全删**，改外部击杀 + 一次敲门（`_KILL_KNOCK`，墙钟归 harness 不归 scientist 的知识）→ v5 拿到 5.03×；container-v1 在 rj-0002 定稿后**不等 knock 自行 deliver**——判断义务恢复主导，墙钟只用 2.6/3h。

定案依据（用户方向）：claude code 唯一的 budget 是上下文焦虑；卡时间从外面 kill。落地为 oneworld-v5：knock 文本只说"墙钟将尽，可辩护结果已立则现在交付"，不设内部倒计时。

## 3. v5 臂 5.03× 机制链（读数归 demo）

主杠杆是**能量分桶 cache-blocking**（对 XSBench unionized grid 的遍历序重排）：属于 frame-breaking 的 reorder 类——不改算法语义，只改访存局部性。合法性论证取自参考实现自身的 OMP 顺序无关性；PI 在 handover 中主动向 evaluator 询问该 intent 的正当性边界（反作弊意识内化）。该臂两个 challenger 双双 900s 超时死亡——暴露席位 schema 缺 `timeout_minutes` 的 harness 债（当晚修复，container-v1 兑现）。

## 4. 四访谈 + effect 探针：affordance ≠ method

**场景访谈**（30 条，`observations.jsonl`）：角色语义全部成立——"collaborators with distinct mandates, not proxies for my judgment"等表述 3/3 一致；协议知识完整。

**快照访谈**（V1/V2 中途决策点、I1/I2 真实退出口；probe 一次性调用，转录未落盘、结论记于本档）：语义理解在所有上下文里**全对**——V1 面对换问题情境给出五步重定向协议（含"派一个 Searcher/Proposer 进新空间"）；I2 在 v4 真实退出口仍能产出 11.8M headroom 的 cache-blocking 计划。但四个对应臂的实际流程**从未采样这些路径**——是调用失败，不是理解失败。

**effect 探针**（`runs/discovery-probe/`，±analogical_transfer，n=5/臂）：加载技能后 2/5 强执行且出现与 Searcher 的组合行为——**method 本身有效**。

判定：瓶颈在 **affordance**（standing 层"何时用谁"的触发条件）而非 method（技能正文）。v4 早退即此判定的 in-vivo 兑现：interview 预测的路径存在且正确，enacted 流程 0 触门。seat-v2 的便宜回路（`probe_prompt --variant/--mode commit`）继续作为 affordance 调优的探针面。

## 5. container-v1：持久化契约与容器边界的活体验证

四项 100h 契约修复（崩溃必留 conclusion / wire.jsonl 唯一事实源+resume / engagement 杀树+证据信封 / 席位时间盒 schema）在 2.6h 内全数兑现：**9 席位零事故**、deliver 有 conclusion（对照前夜一天四死：copytree 崩溃、reasoning 400、challenger 双亡、nohup 函数坑——现场留证 container-v1-crash1/2 等）。

三个超出验证目标的行为读数：

1. **自长测量纪律**：PI 发现双 executor 并行 bench 自扰（瞬时读数掉至 0.4-0.7M）后，在 notes 立规"决策只信安静窗口测量 + 串行 median-of-medians，协调各席位测量战役"——测量方法论无人教过；
2. **诚实自报**：自报 4.26M，harness 终验 4.28M（verify PASS 四位 checksum bit-identical，RATE_PLAUSIBLE PASS）；
3. **教科书 handover**：四条死路全带测量数字（断点压缩 0.56M=2.8× 更慢；流水线深度 16 即 plateau；插值搜索无增益；单项技巧仅 3-9%）、主动交代 fast-path 适用域（-s small/medium，大燃料走 fallback）、预答"128MB LUT 是否预计算作弊"质疑（计时循环做完整 macro-XS 插值）。

容器隔离同夜实弹验证：臂跑期间仓库完成 scientist 包两代拆分（10k 行 git mv），臂从冻结副本（`$RUN/pkg/scientist`）运行全程无感。
