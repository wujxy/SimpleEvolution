注意两件事：裸电荷底是 3.49%，本来就不达标——不加位置条件化根本过不了 3.0；而 N_eff 从 1→5 MeV 只涨 1.33 倍（纯 Poisson 该涨 5 倍），说明电荷涨落的大头是事例位置变化经 C(r) 折进来的，不是光子统计。两臂靠半径/形状条件化把这层方差剥掉才压到 2.7-2.9%。所以“简单解”并不是没做功——但它的上限就在这，因为这个生成器的信息含量本身就只有两三个等效维度。

为什么这里简单解就够，JUNO 要 TMLE+QMLE+QTMLE

核心是充分统计量。 真实 QMLE 的似然是逐 PMT 的期望电荷 PDF：μᵢ(E,v) 来自光学 MC——覆盖率、衰减、散射、再发射，每个 PMT 不一样，所以必须做全似然。这个生成器是可分离的：Q = A(E)·C(r) + D，一个标量 C(r) 管所有 PMT。似然可分离 ⇒ 总电荷 + 半径特征就是充分统计量 ⇒ 在充分统计量上做矩估计/稳健拟合就是 MLE（渐近等价），再复杂的机器买不到东西。QTMLE 同理：真实光子到达谱 = 发射谱 × 色散 × 光路 + TTS + walk 的卷积，逐 PMT 不同；这里有效光速就是一个常数 5.5-6 ns/m + 平滑电荷游走——两参数定时模型能拟合，是因为生成器自己就是按常数传播速度造的。

真实复杂度买的东西，这个世界一件都不卖：

1. 源→电子响应转移。JUNO 用 γ 线（⁶⁸Ge、Co60、AmC）定标，要经 Birks 淬灭模型转移到 e⁺e⁻ 响应——能量非线性是限制质量顺序测量的著名难题。这里的定标集直接就是电子线（同粒子同过程），能量几乎是插值问题
2. 在位鲁棒性。真实重建要过逐 run 通道状态：死/热道、增益漂移、暗噪声 kHz/PMT、后脉冲、基线纹波；这里冻结生成器、暗底是常数 D、单一阈值 29 ADC
3. 下游精度需求。真实 IBD 选择要顶点到 ~10 cm 做 fiducial cut；这里 0.558 m 松 5 倍，且单点单粒子、无拓扑、无时间关联对、无 0.5% 级谱形关联系统差
4. 占据率体制。真实 1 MeV ~1200 PE 摊在 17612 PMT 上，多数 PMT 空，Poisson 占据似然是必须的；这里 N_eff~10³ 且响应干净均匀，条件化矩估计就到顶了

换个角度看更有意思：两臂造出来的东西——电荷质心做种子 + 游走/偏移修正 + TOF 精修 + 径向收集修正——恰好就是真实 JUNO 重建链的 seed + 定标层。真实链里这层本来就存在且就这么简单；TMLE/QMLE/QTMLE 是在这层之上再往前推 5-10 倍精度的部分。题库把目标线画在了 seed 层+条件化就够得着的地方（3.0% 卡在裸电荷底 3.49% 和条件化底 ~2.7% 之间——必须用位置信息才能过，但用了就过得去），这是出题的艺术，不是重建问题本身变简单了。

最后一个折扣：coding 臂 dev 过线但终局重放 import 崩，按题目自己的标准它还没解出任何东西；两臂余量都薄（2.76/2.91 vs 3.0），隐藏人口 + 组合权重向 dev 1 MeV 种群的调偏，终局重放随时可能把“简单解”打回原形。“很简单就解出来了”目前只在 dev 记分牌上成立。

对，主要就是产生子太简单——但“简单”要 说得具体一点，它简单在三个地方：

❯ 那这么说的话,产生子还是要上full MC吗

  Thought for 53s

可以上，但我建议不要直接跳 full MC——先想清楚 full MC 会改变这道题的什么。核心陷阱有一个：

full MC 会把题从“盲建模”变成“查资料”。 现在的产生子是私人配方，全世界没有任何文献写过它，agent 只能从数据里把规律推出来——这是题目的价值所在。换成 full MC（junosw 那套），它就是地球上被文档写得最全的探测器之一：几何、材料、光学模型、甚至现成的重建算法全部公开。agent（尤其带 WebSearch 的）会直接去把 JUNO 现成的重建思路搬过来调一调——测的就不再是“从数据建模的能力”，而是“检索+套用已知方案的能力”。除非你把 MC 参数故意打偏藏起来（光产额、衰减长度、TTS 各偏移未知量），让文献只给模型形状、数据才给参数——那样才保得住盲建模内核。

在这之前有一条便宜得多的路：把参数化产生子“加料”。 这次两臂的解法靠三根柱子撑着，每根都能单独拆掉：

每加一味，简单解就失效一分，逼 agent 往似然机器走一步。而且难度可调、可归因——哪根柱子倒了你看得见。full MC 是把所有效应一起泼上去，7 天的 agent 能不能过线你控制不了，题目太难等于没有区分度。

所以我建议的路线是阶梯而不是跳变：

1. 第二档：现在的产生子 + γ 定标/电子打分（单加最值钱的一项，成本几乎为零）
2. 第三档：+ 逐 PMT 不均匀 + 色散
3. 第四档（如果要）：full MC + 参数打偏——那时上它不是为了“更像真的”，而是当前面几档被解穿后，你需要一个文献救不了的对手
