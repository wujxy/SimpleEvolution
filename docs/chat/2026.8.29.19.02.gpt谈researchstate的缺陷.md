我看完了。这版整体已经很稳，尤其是把 **View = 当前注意力、Memory = 持久认知、Evidence/World = 事实层** 分开，并明确“不替 Scientist 组织搜索空间”，这是我们这轮真正得到的东西。

但如果你准备把它真的称为“定稿”，我会先改两个地方。它们不是文字问题，而是设计上还有一点没闭合。

**第一，`conclusion 从 memory 导出` 我反对。**

文档一边正确地规定 Memory 是选择性的 semantic memory——“未来可能需要重新想起才记”，不是完整日志，也没有逐念登记义务；另一边又写 conclusion 的 `dead_ends / open_questions` 从 closed/open items 导出。 

这两条是矛盾的。

如果 Scientist 有一个临终才意识到的重要 open question，但此前没觉得值得 `remember`，它就不在 Memory 里。此时机械导出反而会让现在 R7 已经证明很强的“临终诚实总结”退化。

所以应该是：

> **conclusion 可以查阅、引用和吸收 Research Memory，但不能被 Memory 定义。**

Scientist 仍然自己做最终科研总结。Memory 是输入，不是 source of truth。

这正符合我们一直坚持的：工具增强 Scientist，不取代 Scientist。

---

**第二，也是现在最大的悬案：§6 对 resurface 砍得可能有一点过头。**

文档现在的逻辑是：

> 先只给 Persist + Retrieve；如果下一 run 证明 Scientist 不主动翻，再增加回顾习惯。

这个实验逻辑有道理。但从**架构逻辑**上，我不会因此得出“Resurface 不属于设计”。

因为 R7 已经证明两个事实同时成立：

1. Scientist **有能力重新想到旧方向**——临终 handover 又想到了 joint TOF+PE；
2. Scientist **在真正需要它的中途里程碑没有想到**——rec#133 就是实际失败。

所以我们面对的不只是 storage failure，还有明确的 **attention / recency failure**。

也就是说：

```text
Memory存在
    ≠
Memory会在正确时刻进入注意力
```

这一点不是猜想，R7 已经给了一半证据。

我同意**现在绝不能上“每次 revise 强制扫 parked”**，那太重，也太像 Harness 教科研。

但我会把架构中的位置先留出来：

```text
Persist
   ↓
Research Memory ← Retrieve
   │
   └── Resurface / awareness   （轻量、内容无关）
```

其中 Resurface 的原则应该先定清楚：

> Harness 最多提醒 Scientist **“你的长期研究记忆存在，当前格局变化后它可能值得重新查阅”**；绝不告诉它应该看哪条、哪条重新升值、下一步做什么。

至于 **v1 是否启用这个 awareness cue**，完全可以像文档说的先实验。

这两个层面得分开：

- **架构上承认 recall attention 是问题的一部分；**
- **产品上先测试纯 retrieval 是否已经足够。**

这样下一 run 如果 Scientist 自己会翻，我们就不用加任何 cue；如果它不会，我们也不是临时发明新机制，而只是打开已经定义好的最后一环。

---

除此以外，我认为里面几个关键决定都应该保留。

尤其是 **Memory 不做 formal graph** 这个判断很好：persistent identity 是承重墙，lineage 只是可选表达能力。文档对这一点已经写得很准确。

还有 **协作者只获得 memory 的存在位置，而不被 Harness 喂内容**，我也认为这比我们前一版更成熟。它真正贯彻了“强 agent 自己履职”：世界、权限和工具给到位，阅读什么是它自己的专业判断。

我唯一还会顺手软化一句：§4.1 里“solver 构成的复述应消失”有点太绝对。 当前实现当然不该成为第二份代码文档，但如果 Scientist 判断“当前 solver 的某个结构”是它做下一步研究判断的重要抽象，那当然应该写。更准确的是：

> **View 不承担同步描述当前实现的义务；只保留 Scientist 判断对当前科研决策有用的世界抽象。**

这仍然让 Scientist 自己决定。

所以我现在对整版的评价是：**主体设计可以定，真正未定的只剩“memory 如何重新进入注意力”这一点。** 而且它不需要现在就被做成复杂机制；我们只需要别在设计层假装这个问题不存在。

如果把这两个地方修掉，我会认为这个 Research Memory 架构已经足够克制，也足够有能力增益，不是在为了结构漂亮而设计。
