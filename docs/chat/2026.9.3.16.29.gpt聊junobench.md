对，而且这里有一个很关键的概念需要再收紧一下：**从 \(E_{\rm true}\) 到最终重建 Charge，并不是一个真正的一维 \(Q=f(E_{\rm true})\)**。真实情况更接近

\[
Q_{\rm reco}
=
F(E_{\rm true},
\mathbf x,
{\rm particle},
{\rm topology},
{\rm detector\ state};
\ \text{randomness})
\]

我们现在的 JunoBench 太简单，本质上就是把这个 \(F\) 压成了几乎一维的线性函数。真实 JUNO 的复杂性，确实主要是在你说的后半段被展开的。

我会重新把整个链路定成下面 **5 层**。

---

## 1. \(E_{\rm true}\rightarrow E_{\rm dep}\rightarrow E_{\rm vis}\)：粒子物理 + LS 本征响应

先不要急着谈 PMT。

\[
E_{\rm true}
\rightarrow
\{E_{{\rm dep},k},\,dE/dx_k,\,{\rm particle}_k\}
\rightarrow
E_{\rm vis}
\]

例如 gamma：

\[
\gamma
\rightarrow e^-_1+e^-_2+\cdots
\]

positron：

\[
e^+
\rightarrow
E_{\rm kin}
+
2\times511\ {\rm keV}\gamma
\]

然后这些带电粒子在 LS 中产生：

\[
N_{\rm scint}
+
N_{\rm Cherenkov}
\]

Birks quenching、Cherenkov threshold、secondary-electron spectrum 等决定了：

\[
E_{\rm vis}
=
f_{\rm physics}(E_{\rm true},p)
\]

所以这里产生的是我们通常说的 **physics nonlinearity**，而且依赖 particle type。JUNO 的 semi-analytical energy-response model 就是这样处理 electron、gamma 和 positron 响应差异的。

这一层其实相对“干净”：

> 它主要回答：**这份真实能量最终变成了多少可见光？**

---

# 2. \(E_{\rm vis}\rightarrow N_\gamma\)：光子产生统计

这里我会稍微修改你的记号。

与其写

\[
E_{\rm vis}\rightarrow E_\gamma
\]

更准确的是

\[
\boxed{E_{\rm vis}\rightarrow N_\gamma}
\]

因为 LS 最后产生的是一个个 optical photons。

均值大致：

\[
\bar N_\gamma
=
Y_\gamma E_{\rm vis}
\]

然后 event-by-event 有统计涨落：

\[
N_\gamma
\sim
P(N_\gamma\mid \bar N_\gamma)
\]

Toy 里面完全可以近似：

\[
N_\gamma\sim {\rm Poisson}(Y_\gamma E_{\rm vis})
\]

严格说实际 scintillation fluctuation 未必是完美 Poisson，但 benchmark 第一阶段这么处理完全合理。

所以：

\[
E_{\rm true}
\rightarrow
E_{\rm vis}
\]

负责**均值的物理非线性**；

而

\[
E_{\rm vis}
\rightarrow
N_\gamma
\]

主要开始产生：

\[
\sigma\propto\sqrt{N}
\]

这样的**统计分辨率**。

---

# 3. \(N_\gamma\rightarrow\) arriving photons：光学传播

我认为这正是 JunoBench 当前最缺的一块。

注意，这一步不应该直接写成

\[
N_\gamma\rightarrow N_{\rm PE}
\]

而应该中间明确存在一个 **photon transport**：

\[
N_\gamma
\rightarrow
\{
\gamma_j:
\lambda_j,
\mathbf n_j,
t_j,
\mathbf x_j
\}
\rightarrow
\{
N_{{\rm hit},i}
\}
\]

每一个 photon 都会经历：

\[
\text{emission}
\rightarrow
\text{propagation in LS}
\rightarrow
\text{absorption/scattering}
\rightarrow
\text{boundary}
\rightarrow
\text{PMT surface}
\]

这一层的物理有：

\[
\boxed{
\begin{aligned}
&\text{attenuation}\\
&\text{absorption/re-emission}\\
&\text{Rayleigh scattering}\\
&\text{refraction}\\
&\text{Fresnel reflection}\\
&\text{total internal reflection}\\
&\text{shadowing}\\
&\text{real detector geometry}
\end{aligned}}
\]

JUNO 本身就因为 LS/acrylic/water 多介质边界存在折射、Rayleigh scattering 和 total reflection，使得 photon propagation 难以用简单解析模型描述。

这里我觉得有一个特别重要的认识：

### 光学传播未必造成强烈的“能量非线性”

如果 photon 相互独立，那么对于固定位置 \(\mathbf x\)：

\[
E[N_{{\rm arrive},i}]
=
p_i(\mathbf x)N_\gamma
\]

它对 \(N_\gamma\) 本身甚至仍然可以近似是线性的。

但是它干了一件更麻烦的事情：

\[
\boxed{
N_\gamma
\rightarrow
\mathbf N_{\rm arrive}
}
\]

从一个 scalar 变成了 **17612 维 detector pattern**。

而且

\[
p_i
=
p_i(
\mathbf x,
\lambda,
\mathbf n,
\text{geometry})
\]

所以：

\[
Q\neq f(E)
\]

而变成了

\[
Q=f(E,\mathbf x).
\]

一旦加入真实 geometry：

\[
Q=f(E,r,\theta,\phi).
\]

这才是你说的“function 变复杂”的一个根本来源。

---

# 4. arriving photon \(\rightarrow\) PE/PMT Charge：探测器响应

光子到了 PMT，并不代表产生一个 PE。

这里应该再拆：

\[
N_{{\rm photon},i}
\rightarrow
N_{{\rm PE},i}
\rightarrow
Q^{\rm PMT}_i
\]

第一步：

\[
p_{\rm det}
=
PDE_i(\lambda,\alpha)
\]

于是

\[
N_{{\rm PE},i}
\sim
{\rm Binomial}
(N_{{\rm photon},i},PDE_i)
\]

大光子数极限下可以近似 Poisson。

而且 JUNO 中：

\[
PDE_i\neq PDE_j.
\]

甚至同一 PMT 表面不同位置的 PDE 都不完全一样。2026 年 JUNO 的 PMT optical model 已经明确引入逐 PMT 的 PDE、反射率以及 photocathode 表面非均匀性，相比统一 PMT model，预测的 PDE 会发生几个百分点的改变。

然后：

\[
N_{{\rm PE},i}
\rightarrow Q_i^{\rm PMT}
\]

也不是简单

\[
Q=N_{\rm PE}.
\]

而应该是：

\[
Q_i^{\rm PMT}
=
\sum_{k=1}^{N_{{\rm PE},i}}q_{ik}
\]

其中

\[
q_{ik}
\sim SPE_i(q).
\]

所以一个 PE 的 charge 本身就是 distribution。

而且 JUNO 还有两种完全不同的 20-inch PMT：

- HPK dynode PMT；
- NNVT MCP-PMT。

它们 gain、SPE charge distribution 等响应不同。

这一步于是同时带来：

### statistical smearing

\[
N_{\rm PE}
\rightarrow Q
\]

不是确定映射。

### channel heterogeneity

\[
Q_i\neq Q_j
\]

即便 illumination 完全一样。

这就是第二个真正打破理想球对称性的来源。

---

# 5. \(Q_{\rm PMT}\rightarrow waveform\rightarrow Q_{\rm reco}\)：电子学 + 波形重建

最后还有一层：

\[
Q^{\rm PMT}_i
\rightarrow
V_i(t)
\rightarrow
ADC_i(t)
\rightarrow
Q^{\rm reco}_i.
\]

PMT 输出首先是一串 pulse：

\[
V_i(t)
=
\sum_k
q_{ik}\,
h_i(t-t_{ik})
\]

然后经过：

- front-end；
- cable；
- amplification；
- shaping；
- sampling；
- ADC；
- pedestal；
- threshold；

最后 waveform reconstruction 算：

\[
\hat Q_i.
\]

于是：

\[
Q^{\rm reco}_i
=
f_{\rm elec}
(
Q^{\rm PMT}_i,
\{t_k\},
{\rm waveform},
{\rm noise}
).
\]

这一层才是很容易产生真正的 **instrumental nonlinearity** 的地方，比如：

- pulse overlap；
- finite sampling；
- threshold；
- saturation；
- baseline；
- charge integration bias；
- SPE charge smearing。

事实上，JUNO 相关研究发现 PMT charge smearing 本身就是影响能量分辨率的重要因素；用 photon-counting waveform reconstruction 替代简单 charge estimation，可以改善最终能量分辨率。

我现在会把我们 JunoBench 的理论模型固定成：

\[
\boxed{
E_{\rm true}
}
\]

↓

### Physics response

\[
\boxed{
E_{\rm dep}
\rightarrow
E_{\rm vis}
}
\]

Birks + Cherenkov + particle interactions

↓

### Photon production

\[
\boxed{
N_\gamma
}
\]

Photon statistics

↓

### Optical transport

\[
\boxed{
\{N_{{\rm photon},i}\}
}
\]

attenuation / scattering / reflection / refraction / TIR / geometry / shadowing

↓

### Detector response

\[
\boxed{

\rightarrow
\{Q_i^{\rm PMT}\}
}
\]

PDE / CE / PMT type / gain / SPE response

↓

### Electronics

\[
\boxed{
\{V_i(t)\}
\rightarrow
\{ADC_i(t)\}
\rightarrow
\{Q_i^{\rm reco},t_i^{\rm reco}\}
}
\]

↓

### Event reconstruction

\[
\boxed{
E_{\rm rec},\mathbf x_{\rm rec}
}
\]

## 而且我觉得这里能得到一个非常重要的 benchmark 设计原则

我们以前可能过度关注：

\[
E_{\rm true}\rightarrow E_{\rm vis}
\]

的非线性。

但如果我们的任务是测试 **reconstruction Scientist**，真正应该重点做复杂的是后半段：

\[
\boxed{
N_\gamma
\rightarrow
\mathbf Q_{\rm reco}
}
\]

因为前半段即使很复杂，最后仍然可能只是：

\[
E_{\rm vis}=f(E_{\rm true})
\]

一个一维函数，网络非常容易学。

真正困难的是：

\[
\boxed{
\mathbf Q
=
F(
E_{\rm vis},
r,\theta,\phi,
\text{optics},
\text{PMT map},
\text{electronics})
}
\]

这才让 **energy 和 position 耦合起来**。

例如两个完全一样的 2 MeV event：

\[
E_1=E_2=2~{\rm MeV}
\]

但

\[
\mathbf x_1=(0,0,0)
\]

和

\[
\mathbf x_2=(15\,{\rm m},0,5\,{\rm m})
\]

最终不仅：

\[
\sum_iQ_i^{(1)}
\neq
\sum_iQ_i^{(2)},
\]

甚至整个

\[
\{Q_i\}
\]

pattern 都会完全不同。

再换一个 \((\theta,\phi)\)，即使 \(r\) 相同：

\[
\sum Q_i(r,\theta_1,\phi_1)
\neq
\sum Q_i(r,\theta_2,\phi_2).
\]

**这才是我们下一版 JunoBench 应该主动制造出来的复杂性。**

换句话说，下一步我觉得不要先问“还要加入哪些 effect”，而应该直接去认真拆 **JUNOSW 的 optical simulation → PMT simulation → electronics simulation 三段到底各自模拟了什么**，然后从里面挑出少数几个真正控制 \(P(\mathbf Q\mid E,\mathbf x)\) 结构的效应做 Toy。这样我们就不会再靠拍脑袋给 benchmark 加 noise 了。
